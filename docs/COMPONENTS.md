# Inventario de componentes reutilizables

| Componente | Fuente | Uso |
|---|---|---|
| Tokens, colores y tipografías | `public/css/tokens.css`, `public/assets/fonts/` | Todas las páginas corporativas |
| Layout y utilidades | `public/css/layout.css`, `public/css/utilities.css` | Estructura responsive |
| Componentes visuales | `public/css/components.css` | Botones, formularios, estados y WhatsApp |
| Navegación | `public/js/navigation.js`, `public/js/site-header.js` | Header y menú móvil |
| Formularios corporativos | `public/js/forms.js` | Formularios existentes |
| Formularios de landing | `public/publicidad-digital/assets/formulario.js` | Atribución y envío configurable |
| Teléfonos | `public/publicidad-digital/assets/telefono.js` | Normalización visual del teléfono |
| WhatsApp | `public/js/whatsapp-widget.js` | Widget flotante compartido |
| Gracias | `public/gracias/index.html` | Destino de conversiones |

Las landings pueden usar estilos aislados para no alterar el sitio corporativo, pero deben reutilizar el contrato de datos y las integraciones del Worker.
