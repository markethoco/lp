# Checklist para una nueva landing

- Definir tipo, URL, objetivo comercial y política de indexación.
- Reutilizar tokens, tipografías, botones, estados y componentes existentes.
- Definir title, description, canonical, robots, Open Graph y Schema.org en HTML.
- Declarar el formulario y sus campos en la configuración del contrato.
- Reutilizar Turnstile, atribución, validación telefónica y página de gracias.
- Asignar `form_id` y nombres de eventos únicos.
- Confirmar mapeo de columnas en Google Sheets antes de publicar.
- Revisar consentimiento, privacidad, accesibilidad y textos alternativos.
- Comprobar móvil, carga de imágenes, desplazamiento horizontal y Core Web Vitals.
- Ejecutar validación JavaScript y pruebas de regresión de formularios existentes.
- Verificar que no se lean secretos ni se habiliten dominios de prueba accidentalmente.
